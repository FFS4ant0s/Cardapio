📝 Descrição do Projeto
O Cardápio Digital é uma aplicação fullstack desenvolvida com Vite + TypeScript no front-end e Spring Boot no back-end. O sistema permite que restaurantes e lanchonetes digitalizem seus cardápios, oferecendo uma interface intuitiva para clientes acessarem os produtos disponíveis, visualizarem detalhes e realizarem pedidos de forma eficiente.

🚀 Tecnologias Utilizadas
🔹 Front-end: Vite, React, TypeScript, TailwindCSS
🔹 Back-end: Spring Boot, Spring Data JPA, PostgreSQL
🔹 Autenticação: Spring Security, JWT
🔹 API REST: Comunicação entre front e back via JSON
🔹 Banco de Dados: PostgreSQL

🔥 Principais Funcionalidades
✅ Cadastro e gerenciamento de produtos (pratos, bebidas, combos)
✅ Interface responsiva e otimizada para dispositivos móveis
✅ Autenticação segura para administradores e clientes
✅ Filtros e categorias para navegação fácil no cardápio
✅ Integração com pagamentos e pedidos em tempo real (futuro)

O projeto visa proporcionar uma experiência rápida e moderna tanto para clientes quanto para estabelecimentos, eliminando a necessidade de cardápios físicos e otimizando o processo de atendimento. 🚀
